Política de privacidad

Canal YouTube Auto · Última actualización: 14 de noviembre de 2026

Qué es esta aplicación

Canal YouTube Auto es una herramienta privada de un solo usuario. Su propietario la usa para subir vídeos originales a su propio canal de YouTube a través de los servicios de la API de YouTube (YouTube API Services).

Uso de los servicios de la API de YouTube

Esta aplicación usa los servicios de la API de YouTube. Al usarla, aceptas las Condiciones del Servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de Privacidad de Google.

Qué datos se usan

  • Autorización OAuth del propietario (permiso youtube.upload): solo para subir vídeos y sus metadatos (título, descripción, etiquetas, miniatura y fecha de publicación) al canal del propietario.
  • Datos públicos de YouTube (títulos, número de visitas, me gusta y comentarios de vídeos públicos, y número de suscriptores de canales públicos): se consultan de forma agregada para decidir qué temas tratar. No se guardan datos personales de nadie.
  • Estadísticas públicas de los vídeos del propio canal: para saber qué temas funcionan mejor.

La aplicación no tiene usuarios externos, no permite iniciar sesión a terceros y no recoge, vende ni comparte datos personales de ninguna otra persona.

Almacenamiento y seguridad

El token de autorización se guarda cifrado como secreto del repositorio de automatización del propietario y solo se usa para las subidas. Los datos públicos consultados se usan en el momento y no se almacenan, salvo un historial interno con los títulos e identificadores de los vídeos del propio canal.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde la página de permisos de seguridad de Google: https://myaccount.google.com/permissions. Al revocarlo, se elimina el token almacenado.

Privacy policy (English summary)

Canal YouTube Auto is a private, single-user tool. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and Google's handling of data is governed by the Google Privacy Policy. It uses the owner's OAuth authorization (youtube.upload) only to upload videos and their metadata to the owner's channel, and reads public, aggregate YouTube statistics to choose topics. It has no external users and does not collect, sell or share anyone's personal data. The token is stored as an encrypted repository secret. Access can be revoked at any time at https://myaccount.google.com/permissions. Contact: github.com/angelrs-15
